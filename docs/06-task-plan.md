# 06 — Delivery and handoff

The original event schedule and task assignments are no longer an active project plan. This document records the delivered scope and the practical checks to make when sharing a release.

## Delivered

- Production web app: [earthpod.earth](https://earthpod.earth)
- Introduction, listening guide, two chapters, record page, and accessibility statement.
- Backend data-preparation and sonification tools, with tests and reproducibility notes.
- Source credits and AI-use disclosure in the project documentation.

## Before presenting or sharing a new deployment

1. Open the production URL from the device and browser used for the presentation.
2. Play each chapter and confirm the video, sound, captions, and controls remain synchronized.
3. Check keyboard navigation and the intended screen-reader flow; confirm audio does not autoplay.
4. Confirm the repository links, source credits, accessibility statement, and AI-use disclosure are visible and current.
5. Keep a local copy of any presentation media needed when the network is unavailable.

These are release-time checks, not claims that a particular deployment or event submission has been verified by this document.
